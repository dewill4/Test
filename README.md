# Aibro.ai Test

This repository contains a simple Python implementation for the Aibro.ai test.

## Features

- Simple greeting function with customizable name
- Basic arithmetic operations (addition)
- Comprehensive unit tests

## Usage

Run the main module:
```bash
python3 aibro_test.py
```

## Testing

Run the unit tests:
```bash
python3 -m unittest test_aibro.py -v
```

## Module Documentation

### `greet(name: str = "World") -> str`
Generate a greeting message for the given name (default: "World").

### `add(a: int, b: int) -> int`
Add two numbers together and return the result.
